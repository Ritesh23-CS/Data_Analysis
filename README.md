📚 InfiniteSelves: Personal Library Management System
A Power BI Data Analytics Project

📋 Project Overview
This project transforms a personal reading collection into a functional Business Intelligence tool. By moving beyond simple lists, this dashboard provides a high-level overview of reading habits, library growth, and content distribution across languages and genres.

The goal was to create an interactive system that helps a reader identify "reading gaps" (genres they ignore) and track their progress from "To-Read" to "Completed."

🛠️ Tech Stack & Tools
Data Source: Microsoft Excel (Structured tables)

Data Visualization: Power BI Desktop

Data Transformation: Power Query (Cleaning and formatting)

Design: Custom theme development for a "Library Aesthetic"

📊 Key Insights & Features
KPI Tracking: Real-time monitoring of Total Books, Completion Rate, and Average Rating.

Genre Distribution: A breakdown of library diversity (Self-Help, Fiction, Biography, etc.).

Interactivity: Fully dynamic filtering by Year, User ID, and Genre to drill down into specific subsets of data.

Status Monitoring: A dedicated "Reading Status" bar chart to visualize the current pipeline of books.

Top Performers: Automated ranking of "Most Read Authors" to identify favorite contributors.

🧠 Data Processing Highlights
To make this dashboard functional, I performed several data modeling steps:

Data Cleaning: Standardized author names and genre categories using Power Query.

Date Modeling: Created relationships to allow for "Filter by Year" functionality.

UI/UX Design: Implemented a cohesive color palette and card-based layout for high readability and "scannability."

🚀 How to Use This Repository
View the Dashboard: Download the .pbix file and open it in Power BI Desktop.

Explore the Data: The underlying dataset is available in the Data/ folder as an Excel file.

Interact: Use the slicers on the right side of the dashboard to filter the visuals.
